# Go SDK Functions Example

Copy these functions into a Go backend, CLI, or worker when you want to automate Pxxl.

```bash
PXXL_API_KEY=pxxl_... go run .
```

The example includes:

- Deploying a local codebase with the SDK
- Uploading and listing CDN assets
- Searching domains and reading TLD prices

Docs: https://docs.pxxl.app  
Deploy on Pxxl: https://pxxl.app

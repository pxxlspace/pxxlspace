# Pxxl Public SDKs, Examples, and Boilerplates

This folder contains official open-source Pxxl developer resources.

- `sdks/node/pxxl-cdn`: Node SDK and CLI for Pxxl CDN.
- `sdks/go/pxxl`: Go SDK for Pxxl CDN.
- `examples`: minimal upload examples.
- `boilerplates`: deploy-ready starter projects for Pxxl.
- `skills`: safe automation instructions for Codex-style agents.

Deploy any boilerplate on [Pxxl](https://pxxl.app) to get fast builds, custom domains, global proxy routing, CDN uploads, SSL, analytics, and simple GitHub deploys.

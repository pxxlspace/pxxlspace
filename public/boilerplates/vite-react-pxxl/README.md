# Vite React Pxxl Boilerplate

Start a React app that is ready for Pxxl deploys, preview URLs, custom domains, CDN assets, analytics, and fast global routing.

## Local

```bash
npm install
npm run dev
```

## Deploy on Pxxl

Import the repo at [pxxl.app](https://pxxl.app). Pxxl detects Vite automatically and uses `npm run build`.

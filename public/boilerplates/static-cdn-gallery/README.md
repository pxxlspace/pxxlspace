# Static CDN Gallery Boilerplate

Deploy a fast static gallery on Pxxl for portfolios, brand assets, image showcases, and product pages.

Pxxl gives this starter instant SSL, custom domains, global routing, CDN uploads, analytics, and simple GitHub deployments.

## Deploy

1. Create a new repository from this folder.
2. Push it to GitHub.
3. Import it at [pxxl.app](https://pxxl.app).

No build command is required.

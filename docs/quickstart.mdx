This guide takes you from a new account to a live app. If you prefer the terminal, follow [Deploy with the CLI](/get-started/cli) instead.

<Steps>
  <Step title="Create an account">
    Sign up at [pxxl.app/signup](https://pxxl.app/signup). You can sign in with GitHub.
  </Step>
  <Step title="Open Deploy">
    In the dashboard, choose **Deploy**.
  </Step>
  <Step title="Pick your code">
    Choose **GitHub**, install the Pxxl GitHub App, and give it access to your repository. Then pick the repository and branch.

    Other options: GitLab, a Docker image, a Dockerfile, a zip upload (Pxxl Drop), a template, or WordPress. See [Deployment sources](/deploy/sources).
  </Step>
  <Step title="Check the settings">
    Pxxl detects your framework and fills in the install, build, and start commands, the port, and the output folder. Change anything that's wrong. Add your environment variables here too.
  </Step>
  <Step title="Deploy">
    Select **Deploy Project** and watch the build log. When it finishes, your app is live at `https://<name>.pxxl.pro` (or the suffix you picked).
  </Step>
</Steps>

From now on, every push to the branch deploys again automatically.

## Two things to check

**Web apps and APIs** must listen on the `PORT` environment variable and bind to `0.0.0.0`:

```js
const port = process.env.PORT || 3000;
app.listen(port, "0.0.0.0");
```

**Static sites** need no server. Pxxl publishes the build output folder (for example `dist`), or the folder with your `index.html`.

## Add your domain

Open **Domains**, choose **Add Domain**, pick the project, and add the DNS records Pxxl shows. HTTPS is set up for you. Full steps: [Domains](/domains/overview).

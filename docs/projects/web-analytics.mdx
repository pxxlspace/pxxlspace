**Web Analytics** shows traffic that reaches a project through the Pxxl edge. It focuses on visitors and requests, while [Monitoring](/projects/monitoring) focuses on runtime resources.

## What the tab shows

| Metric | Meaning |
| --- | --- |
| **Visitors** | Unique visitors identified during the selected timeframe. |
| **Online now** | Unique sessions seen in the last five minutes. |
| **Bandwidth** | Bytes sent and received by the project. |
| **Top Country** | The location contributing the largest share of located traffic. |
| **Peak Time** | The busiest activity window in UTC. |
| **Request Activity** | Requests, bandwidth, average latency, and traffic outcomes over time. |
| **Top Paths** | The routes receiving the most traffic. |
| **Domain Index** | Traffic grouped by the domains attached to the project. |
| **Recent Edge Requests** | Recent request details such as method, path, status, latency, and location. |

## Choose a timeframe

Use the timeframe control to view **24h**, **48h**, **72h**, **7d**, or **30d**. Select **Refresh** when you want to request the latest measurements.

Analytics become useful after traffic reaches the project. A new project may show empty charts until visitors and requests have been recorded.

## Analytics and monitoring are different

- **Web Analytics** explains what visitors and requests are doing.
- **Monitoring** explains how much CPU and memory the running service is using.
- **Live Logs** shows the application's own runtime output.

Use all three when investigating a slow or failing application.

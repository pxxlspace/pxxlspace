---
title: "Servers"
description: "Link your own servers to Pxxl and manage them from the terminal."
---

Bring your own server (any Linux machine you run: a VPS, a home box, a VM) and Pxxl deploys to it and watches it. Included on Plus and above.

## Link a server

```bash
pxxl servers add my-vps
```

It prints a one-time install command. Run it on the server as root; the server shows as online within a minute. Lost the machine or reinstalled it? `pxxl servers link my-vps` prints a fresh command.

## Watch it

```bash
pxxl servers                       # every server, online or not, with CPU, memory and last check-in
pxxl servers show my-vps           # details and apps
pxxl servers health my-vps         # agent, container runtime, service, tunnel, disk, memory
pxxl servers metrics my-vps        # load, memory and disk now, with trends
pxxl servers apps my-vps
pxxl servers events my-vps         # connects, drops, restarts
pxxl servers alerts my-vps         # open and resolved alerts
```

With one server you can leave its name out. With several, the CLI asks (type a number or the name).

## Act on it

```bash
pxxl servers logs my-vps --app web       # recent output of an app
pxxl servers restart my-vps --app web    # or start / stop one app
pxxl servers prune my-vps                # free space taken by old images
pxxl servers update my-vps               # update the Pxxl agent
```

`stop`, `prune` and `update` ask first; pass `--yes` in scripts.

## Run operations

```bash
pxxl servers ops                         # what you can run
pxxl servers run my-vps system.summary
pxxl servers run my-vps disk.usage
pxxl servers run my-vps app.logs --app web -n 200
pxxl servers run my-vps <change-op> --change   # operations that change the server
```

## Settings

```bash
pxxl servers settings my-vps                         # alerts and auto-update
pxxl servers settings my-vps --set alertEmail=false
pxxl servers rename my-vps vps-frankfurt
pxxl servers rm my-vps --yes                         # unlink; the machine keeps running
```

Add `--team <id>` to work with a spaceship's servers. API keys need the **All** or **Servers** scope; a key made for a spaceship only ever sees that spaceship's servers.

## Share a local app

```bash
pxxl tunnel 3000
```

The CLI connects out over HTTPS, so it works behind NAT, firewalls and hotel Wi-Fi, and prints a public URL. Requests to it reach `localhost:3000`; WebSockets are relayed too. Press Ctrl+C to stop. If the connection drops, it reconnects on its own.

`pxxl tunnel 3000` reuses the tunnel named `<machine>-3000`, or creates it, so the URL stays the same between runs. Pick the name with `--name`.

<ParamField body="--auth" type="user:password">
  Visitors must sign in before anything reaches your app. The credentials are checked on your machine and are not passed to your app.
</ParamField>

<ParamField body="--header" type="Name: value">
  Add a header to every request to your app. Repeat for more.
</ParamField>

<ParamField body="--response-header" type="Name: value">
  Add a header to every response visitors get.
</ParamField>

<ParamField body="--host-header" type="string" default="rewrite">
  `rewrite` sends your app its own host (`localhost:3000`), `preserve` sends the public host, or give the host your app expects.
</ParamField>

<ParamField body="--json" type="flag">
  One JSON line per request, for scripts.
</ParamField>

The target can be a port or a URL, such as `http://localhost:8080/api` or `https://app.test` (self-signed certificates are accepted unless you pass `--strict-tls`).

```bash
pxxl tunnel list                        # your tunnels and whether they are online
pxxl tunnel create demo --to 5173
pxxl tunnel connect demo --to 5173
pxxl tunnel rotate demo                 # token for the standalone pxxl-tunnel binary
pxxl tunnel delete demo
```

Tunnels are included on Plus (2), Pro (10) and Enterprise (50). Requests can be up to 10 MB on Plus and 16 MB on Pro and Enterprise.

## Catch webhooks

```bash
pxxl webhook create stripe
```

Give the URL it prints to the provider. Pxxl records every request and answers with the status you choose (`--status`, default 200).

```bash
pxxl webhook listen stripe --forward http://localhost:3000/webhooks
```

`listen` streams each new request to your machine as it arrives, with its original headers (signatures included) and body. The request's path is appended to `--forward` unless you pass `--exact-path`.

```bash
pxxl webhook requests stripe            # what arrived
pxxl webhook show stripe <request-id>   # headers and body
pxxl webhook replay stripe <request-id> --to https://staging.example.com/webhooks
pxxl webhook pause stripe               # answer 503 and record nothing
pxxl webhook clear stripe               # delete stored requests
```

With `--forward <url>` on `create`, Pxxl itself forwards each request to a public URL (Plus and above). Requests are kept 24 hours on Free, 7 days on Plus, 30 days on Pro and 90 days on Enterprise.

## Check a URL or domain

```bash
pxxl check http example.com             # redirects, timings, headers, TLS
pxxl check domain example.com           # DNS records and certificate
pxxl tools                              # what your plan includes
```

## API keys

Tunnels and webhooks need an API key with the **All** or **Tools** scope. Read access lists and inspects; creating, connecting and replaying need read and write.

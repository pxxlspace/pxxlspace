## Analytics

```bash
pxxl analytics project proj_123 --timeframe 7d
pxxl analytics domain dom_123 --timeframe 24h
pxxl analytics user-domain app.example.com --timeframe 30d
```

## Teams

```bash
pxxl teams list
pxxl teams get team_123
pxxl teams use team_123
pxxl teams current
```

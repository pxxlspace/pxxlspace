## Create a database

<ParamField body="name" type="string" required>
  Database name shown in Pxxl.
</ParamField>

<ParamField body="type" type="string" required>
  `postgres` (or `postgresql`), `mysql`, `mariadb`, `mongodb`, `redis`, `dragonfly`, `keydb`, or `clickhouse`.
</ParamField>

<ParamField body="description" type="string">
  Short note about the database purpose.
</ParamField>

<ParamField body="projectId" type="string">
  Project connected to the database.
</ParamField>

<ParamField body="dailyBackupsEnabled" type="boolean" default="false">
  Enables supported daily backups.
</ParamField>

<ParamField body="teamId" type="string">
  Team that owns the database. Node.js only; in Go, Python, and Rust the database goes to the key's own account or team.
</ParamField>

<Tabs>
  <Tab title="Node.js">
    ```ts
    const result = await pxxl.databases.create({
      name: "app-db",
      type: "postgres",
      projectId: "proj_123",
      dailyBackupsEnabled: true,
    });
    ```
  </Tab>
  <Tab title="Go">
    ```go
    result, err := client.CreateDatabase(ctx, map[string]any{
      "name": "app-db", "type": "postgres", "projectId": "proj_123",
      "dailyBackupsEnabled": true,
    })
    ```
  </Tab>
  <Tab title="Python">
    ```python
    result = client.create_database({
        "name": "app-db", "type": "postgres",
        "projectId": "proj_123", "dailyBackupsEnabled": True,
    })
    ```
  </Tab>
  <Tab title="Rust">
    ```rust

        "name": "app-db", "type": "postgres",

    ```
  </Tab>
</Tabs>

## Database operations

| Operation | Node.js | Parameters | Returns |
| --- | --- | --- | --- |
| List | `databases.list(teamId?)` | `teamId?` | `{ databases, total, success? }` |
| Get | `databases.get(id, teamId?)` | Database ID, `teamId?` | `{ database, success? }` |
| Create | `databases.create(input)` | Fields above | `{ database, success? }` |
| Update | `databases.update(id, input)` | `name?`, `description?`, `teamId?` | `{ database, success? }` |
| Delete | `databases.delete(id, teamId?)` | Database ID, `teamId?` | Action result |
| Start | `databases.start(id, teamId?)` | Database ID, `teamId?` | Action result |
| Stop | `databases.stop(id, teamId?)` | Database ID, `teamId?` | Action result |
| Restart | `databases.restart(id, teamId?)` | Database ID, `teamId?` | Action result |
| Stats | `databases.stats(id, teamId?)` | Database ID, `teamId?` | Runtime status and resource summary |
| Metrics | `databases.metrics(id, teamId?)` | Database ID, `teamId?` | Time-series CPU and memory metrics |
| Usage | `databases.usage(id, teamId?)` | Database ID, `teamId?` | Storage, network, and plan usage |
| Tables | `databases.tables(id, teamId?)` | Database ID, `teamId?` | Table or collection metadata |
| Credential | `databases.credential(id, field, teamId?)` | `password`, `root-password`, or `database-url` (`url` also works) | `{ success, field, value }` |

## Runtime responses

Start, stop, and restart calls return the accepted action and current state.

```json
{
  "success": true,
  "message": "Database start requested",
  "databaseId": "db_123",
  "status": "starting"
}
```

Metrics and usage calls return structured values that can gain new metrics over time.

```json
{
  "databaseId": "db_123",
  "status": "running",
  "cpu": { "current": 0.12, "unit": "vCPU" },
  "memory": { "currentBytes": 268435456 },
  "storage": { "usedBytes": 104857600, "limitBytes": 10737418240 },
  "series": []
}
```

## Reveal a credential

```ts
const result = await pxxl.databases.credential("db_123", "password");
const password = result.value;
```

```json
{
  "success": true,
  "field": "password",
  "value": "sensitive-value"
}
```

<Warning>
  Credential responses contain sensitive data. Do not log, cache, or send them to a browser.
</Warning>

## Other languages

Go, Python, and Rust use one method for start, stop, and restart.

| Operation | Go | Python | Rust |
| --- | --- | --- | --- |
| List, get | `ListDatabases(ctx, teamID)`, `GetDatabase(ctx, id, teamID)` | `list_databases(team_id=None)`, `get_database(id, team_id=None)` | `list_databases(team_id)`, `get_database(id, team_id)` |
| Create | `CreateDatabase(ctx, input)` | `create_database(values)` | `create_database(input)` |
| Update | `UpdateDatabase(ctx, id, teamID, input)` | `update_database(id, values, team_id=None)` | `update_database(id, input, team_id)` |
| Delete | `DeleteDatabase(ctx, id, teamID)` | `delete_database(id, team_id=None)` | `delete_database(id, team_id)` |
| Start, stop, restart | `DatabaseAction(ctx, id, "restart", teamID)` | `database_action(id, "restart")` | `database_action(id, "restart", team_id)` |
| Stats, metrics, usage, tables | `DatabaseStats`, `DatabaseMetrics`, `DatabaseUsage`, `DatabaseTables` | `database_stats`, `database_metrics`, `database_usage`, `database_tables` | `database_stats`, `database_metrics`, `database_usage`, `database_tables` |
| Credential | `RevealDatabaseCredential(ctx, id, field, teamID)` | `reveal_database_credential(id, field)` | `reveal_database_credential(id, field, team_id)` |

The action must be `start`, `stop`, or `restart`. Any other value fails before a request is sent.

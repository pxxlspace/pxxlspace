---
title: "MCP"
description: "Call Pxxl tools and resources through the Model Context Protocol."
---

The default endpoint is `https://mcp.pxxl.app/mcp`. The SDK sends JSON-RPC 2.0 requests with your API key and protocol version `2025-06-18`, and returns the inner `result`. To connect an AI client to Pxxl instead, see [MCP](/ai/mcp).

In Node.js, `pxxl.mcp` uses the client's `apiKey`. Pass `mcpApiKey` or `mcpEndpoint` to the `Pxxl` constructor to change either one.

```mermaid
sequenceDiagram
  participant App
  participant SDK
  participant MCP as Pxxl MCP
  App->>SDK: listTools()
  SDK->>MCP: tools/list
  MCP-->>SDK: result.tools
  App->>SDK: callTool(name, arguments)
  SDK->>MCP: tools/call
  MCP-->>SDK: structured result
```

## MCP operations

| Operation | Node.js | Parameters | Returns |
| --- | --- | --- | --- |
| Initialize | `mcp.initialize()` | None | Protocol version, capabilities, and server info |
| Ping | `mcp.ping()` | None | Empty successful result |
| List tools | `mcp.listTools()` | None | Tool definition array |
| Call tool | `mcp.callTool(name, arguments?)` | Tool name and arguments | MCP tool result |
| List resources | `mcp.listResources()` | None | Resource definition array |
| Read resource | `mcp.readResource(uri)` | Resource URI | MCP resource contents |
| Raw RPC | `mcp.rpc(method, params?)` | JSON-RPC method and params | Inner JSON-RPC result |

In Go, Python, and Rust, one method sends any JSON-RPC call:

| SDK | Method |
| --- | --- |
| Go | `client.MCP(ctx, endpoint, method, params)`, where an empty `endpoint` uses the default |
| Python | `client.mcp_rpc(method, params=None, endpoint=...)` |
| Rust | `client.mcp_rpc(method, params, endpoint)`, where `None` uses the default |

## List tools

<Tabs>
  <Tab title="Node.js">
    ```ts
    const tools = await pxxl.mcp.listTools();
    ```
  </Tab>
  <Tab title="Go">
    ```go
    result, err := client.MCP(ctx, "", "tools/list", map[string]any{})
    tools := result["tools"]
    ```
  </Tab>
  <Tab title="Python">
    ```python
    result = client.mcp_rpc("tools/list")
    tools = result["tools"]
    ```
  </Tab>
  <Tab title="Rust">
    ```rust
    let result = client.mcp_rpc("tools/list", json!({}), None).await?;
    let tools = &result["tools"];
    ```
  </Tab>
</Tabs>

## Call a tool

<ParamField body="name" type="string" required>
  Tool name returned by `listTools()`.
</ParamField>

<ParamField body="arguments" type="object" default="{}">
  Arguments validated against the tool input schema.
</ParamField>

```ts
const result = await pxxl.mcp.callTool("projects_list", { limit: 10 });
```

```json
{
  "content": [
    {
      "type": "text",
      "text": "{\"projects\":[],\"total\":0}"
    }
  ],
  "structuredContent": {
    "projects": [],
    "total": 0
  },
  "isError": false
}
```

MCP errors can arrive as a JSON-RPC error or as `isError: true` inside a tool result. The SDK throws for JSON-RPC errors. Check `isError` yourself for tool-level failures.

`pxxl.mcp` throws a plain `Error` with the JSON-RPC message. The flat `pxxl.mcpRPC(method, params?, endpoint?)` method throws `PxxlAPIError` instead. Go returns an error, Python raises `RuntimeError` for a JSON-RPC error and `PxxlAPIError` for an HTTP error, and Rust returns `PxxlError::Api`.

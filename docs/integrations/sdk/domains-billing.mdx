## Purchase domains

<ParamField body="domains" type="array" required>
  Domains to purchase.
</ParamField>

<ParamField body="domains[].domainName" type="string" required>
  Full domain name.
</ParamField>

<ParamField body="domains[].years" type="number">
  Registration length in years.
</ParamField>

<ParamField body="domains[].addons" type="array">
  Add-ons in the form `{ id }`.
</ParamField>

<ParamField body="domains[].nameservers" type="string[]">
  Optional custom nameservers.
</ParamField>

<ParamField body="customerId" type="string | number">
  Saved customer used as the registrant. The SDK sends it as `contactId`.
</ParamField>

<ParamField body="contact" type="object">
  Inline registrant contact when no customer ID is used.
</ParamField>

<ParamField body="address" type="object">
  Inline registrant address.
</ParamField>

<ParamField body="currency" type="NGN | USD">
  Checkout currency. It is also used for the payment link.
</ParamField>

<ParamField body="teamId" type="string">
  Team that owns the purchase.
</ParamField>

<Tabs>
  <Tab title="Node.js">
    ```ts
    const { purchase, payment } = await pxxl.domains.checkout({
      customerId: customer.id,
      domains: [{ domainName: "example.com", years: 1 }],
      currency: "USD",
    });

    return Response.redirect(payment.paymentUrl, 303);
    ```
  </Tab>
  <Tab title="Go">
    ```go
    checkout, err := client.PurchaseDomainCheckout(ctx, map[string]any{
      "customerId": customerID,
      "domains": []map[string]any{{"domainName": "example.com", "years": 1}},
      "currency": "USD",
    })
    ```
  </Tab>
  <Tab title="Python">
    ```python
    checkout = client.purchase_domain_checkout({
        "customerId": customer["id"],
        "domains": [{"domainName": "example.com", "years": 1}],
        "currency": "USD",
    })
    ```
  </Tab>
  <Tab title="Rust">
    ```rust
    let checkout = client.purchase_domain_checkout(json!({
        "customerId": customer["id"],
        "domains": [{"domainName": "example.com", "years": 1}],
        "currency": "USD"
    })).await?;
    ```
  </Tab>
</Tabs>

The checkout call creates the invoice, then asks for its payment link, and returns both as `purchase` and `payment`. To store the invoice before you fetch a link, call `domains.purchase()` and then `invoices.paymentUrl()` yourself. In Go, Python, and Rust, `purchase` is the raw API response, so the invoice ID is under `data`.

Treat the hosted payment URL as a redirect destination, not proof of payment. Read the invoice again from your backend and require a paid state before provisioning the domain or any plan-gated service.

**Purchase response**

```json
{
  "invoiceId": "inv_123",
  "invoice": {
    "id": "inv_123",
    "status": "pending",
    "currency": "USD",
    "grandTotal": 19,
    "expiresAt": "2026-08-18T08:00:00Z"
  },
  "computedTotal": 19,
  "taxAmount": 0,
  "grandTotal": 19,
  "currency": "USD",
  "domains": [{ "domainName": "example.com", "years": 1 }],
  "domainErrors": []
}
```

**Payment URL response**

```json
{
  "paymentUrl": "https://checkout.example/pxxl/inv_123",
  "checkoutUrl": "https://checkout.example/pxxl/inv_123",
  "reference": "pxxl_inv_123",
  "invoiceId": "inv_123",
  "currency": "USD",
  "paymentUrlExpiresAt": "2026-08-18T08:00:00Z"
}
```

## Domain orders and add-ons

An order collects domains before you create an invoice for them. Orders are in Node.js only.

| Operation | Node.js | Parameters | Returns |
| --- | --- | --- | --- |
| Create order | `domains.createOrder(input)` | `domains` (names), `customerId?` | Order result |
| List orders | `domains.listOrders()` | None | `{ orders, count }` |
| Get order | `domains.getOrder(id)` | Order ID | Order detail |
| Change length | `domains.updateOrderDuration(domainId, duration)` | Order domain ID, years | Updated order |
| Add add-ons | `domains.addOrderAddons(domainId, addonIds)` | Order domain ID, add-on IDs | Updated order |
| Add-on invoice | `domains.createAddonInvoice(domainId, addonIds, currency?)` | Owned domain ID, add-on IDs, `NGN` or `USD` (default `NGN`) | Invoice for the add-ons |

Turn an order into an invoice with `billing.create({ domainOrderId })`, then get a link with `billing.paymentLink(id)`.

## Connect a domain

<ParamField body="domain" type="string" required>
  Hostname to connect.
</ParamField>

<ParamField body="projectId" type="string" required>
  Project that receives traffic.
</ParamField>

<ParamField body="serviceAlias" type="string">
  Service target for a multi-service project.
</ParamField>

<ParamField body="servicePort" type="number">
  Service port when the route needs an explicit target.
</ParamField>

<ParamField body="alias" type="boolean" default="false">
  Marks this hostname as an alias route.
</ParamField>

```ts
const connected = await pxxl.domains.connect({
  domain: "api.example.com",
  projectId: "proj_123",
  serviceAlias: "api",
});
```

```json
{
  "error": false,
  "domainId": "dom_123",
  "domain": { "name": "api.example.com", "status": "pending_dns" },
  "serviceAlias": "api",
  "expectedARecordIp": "203.0.113.10",
  "routeStatus": "pending"
}
```

## DNS records and nameservers

See [DNS](/domains/dns) for the records Pxxl manages.

<ParamField body="type" type="string" required>
  `A`, `AAAA`, `CNAME`, `TXT`, `MX`, or another supported record type.
</ParamField>

<ParamField body="name" type="string" required>
  Record name. Use `@` for the apex.
</ParamField>

<ParamField body="value" type="string" required>
  Record value.
</ParamField>

<ParamField body="ttl" type="number">
  Time to live in seconds.
</ParamField>

<ParamField body="priority" type="number">
  Priority for records such as `MX`.
</ParamField>

<ParamField body="proxied" type="boolean">
  Sends traffic for the record through the Pxxl proxy.
</ParamField>

```ts
const result = await pxxl.domains.upsertDNSRecord("dom_123", {
  type: "A",
  name: "@",
  value: "203.0.113.10",
  ttl: 300,
});
```

```json
{
  "error": false,
  "records": [
    { "id": "rec_123", "type": "A", "name": "@", "value": "203.0.113.10", "ttl": 300 }
  ]
}
```

| Operation | Node.js | Parameters | Returns |
| --- | --- | --- | --- |
| List records | `domains.dnsRecords(id, teamId?)` | Domain ID, `teamId?` | `{ records }` |
| Create record | `domains.upsertDNSRecord(id, input)` | Record fields above | Updated record collection |
| Replace records | `domains.replaceDNSRecords(id, input)` | `recordId?` or `records[]` | Updated record collection |
| Delete record | `domains.deleteDNSRecord(id, input)` | `recordId`, `zoneId?`, `teamId?` | Updated record collection or action result |
| Change logs | `domains.changeLogs(id, teamId?)` | Domain ID, `teamId?` | DNS change history |
| Roll back | `domains.rollbackDNSChange(id, logId, teamId?)` | Domain ID and log ID | Restored records |
| Set nameservers | `domains.updateNameservers(id, nameservers, teamId?)` | Nameserver array | Nameserver state |
| Reset nameservers | `domains.resetNameservers(id, teamId?)` | Domain ID | Nameserver state |
| Verify nameservers | `domains.verifyNameservers(id, teamId?)` | Domain ID | Verification result |

## Resell domains to your users

On Pro and up, `pxxl.reseller` (Go `client.Reseller()`, Python `client.reseller`, Rust `client.reseller()`) buys, renews and manages domains for your own customers with a reseller key, charged to your wallet. See [Domain reseller](/tools/domain-reseller).

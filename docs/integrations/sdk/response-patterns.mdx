title: "Response patterns"
description: "Understand returned data, lists, files, empty results, and errors across every Pxxl SDK."
---

SDK methods return the parsed JSON body for successful calls. You do not need to check HTTP status codes. Failed calls throw or return an error.

## Single resources

Create and get methods return a resource or a small named wrapper.

```json
{
  "bucket": {
    "id": "bucket_123",
    "name": "uploads",
    "visibility": "private",
    "status": "active"
  }
}
```

Some Node.js methods unwrap the resource for you. For example, `customers.create()` returns the customer and `cdn.upload()` returns the asset.

| SDK | What you get back |
| --- | --- |
| Node.js | Typed objects where available, with small API wrappers kept when they carry useful metadata |
| Go | Typed structs for CDN, domains, cron jobs, and deploys; `map[string]any` for everything else |
| Python | Dictionaries that keep the API's JSON shape |
| Rust | Typed structs for a few core calls; `serde_json::Value` for everything else |

## Lists

List methods return an array with a count or pagination details.

```json
{
  "buckets": [],
  "total": 0
}
```

```json
{
  "assets": [],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 0,
    "totalPages": 0
  }
}
```

Go unwraps a few lists into slices. `ListAssets`, `ListTLDs`, `ListDomains`, `ListCronJobs`, and `ListCronJobRuns` return the array directly.

## Actions

Start, stop, trigger, resync, and similar calls return the API's action result.

```json
{
  "success": true,
  "message": "Action accepted"
}
```

Some delete methods return nothing. In Node.js these resolve to `undefined`. In Go they return only an `error`, in Python `None`, and in Rust `()`.

## Files

Download methods return binary data instead of JSON.

| SDK | Return value |
| --- | --- |
| Node.js | `Blob` |
| Go | `[]byte` |
| Python | `bytes` |
| Rust | `Vec<u8>` |

## Errors

A non-2xx response raises an SDK error. Plan and resource limits come back with structured fields.

```json
{
  "code": "DOMAIN_LIMIT_EXCEEDED",
  "message": "Your current plan domain limit has been reached.",
  "limit": 5,
  "used": 5
}
```

The SDK reads these fields from the body or from a nested `details` object. It fills `current` from `current` or `used`. A call counts as a plan gate when the body sets `upgradeRequired`, the status is `402`, or the code contains `PLAN`, `LIMIT`, or `UPGRADE`.

<Tabs>
  <Tab title="Node.js">
    ```ts
    import { PxxlAPIError, isPlanGateError } from "@pxxlapp/pxxl";

    try {
      await pxxl.storage.createBucket({ name: "uploads" });
    } catch (error) {
      if (isPlanGateError(error)) {
        console.log(error.code, error.limit, error.current, error.requiredPlan);
      } else if (error instanceof PxxlAPIError) {
        console.log(error.status, error.message, error.details);
      }
    }
    ```
  </Tab>
  <Tab title="Go">
    ```go
    result, err := client.CreateStorageBucket(ctx, map[string]any{"name": "uploads"})
    if err != nil {
      var apiErr *pxxl.APIError
      if errors.As(err, &apiErr) && apiErr.IsPlanGate() {
        log.Println(apiErr.Code, apiErr.Limit, apiErr.Current, apiErr.RequiredPlan)
      }
    }
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from pxxl import PxxlAPIError, is_plan_gate_error

    try:
        result = client.create_storage_bucket({"name": "uploads"})
    except PxxlAPIError as error:
        if is_plan_gate_error(error):
            print(error.code, error.limit, error.current, error.required_plan)
    ```
  </Tab>
  <Tab title="Rust">
    ```rust
    if let Err(error) = client.create_storage_bucket(json!({ "name": "uploads" })).await {
        if error.is_plan_gate() {
            eprintln!("Upgrade required for another storage bucket");
        }
    }
    ```
  </Tab>
</Tabs>

| SDK | Error type | Fields |
| --- | --- | --- |
| Node.js | `PxxlAPIError` | `status`, `message`, `details`, `code`, `limit`, `current`, `requiredPlan`, `upgradeRequired` |
| Go | `*pxxl.APIError` | `StatusCode`, `Message`, `Body`, `Code`, `Limit`, `Current`, `RequiredPlan`, `UpgradeRequired`, and `IsPlanGate()` |
| Python | `PxxlAPIError` | `status_code`, `message`, `body`, `details`, `code`, `limit`, `current`, `required_plan`, `upgrade_required` |
| Rust | `PxxlError::Api` | `status`, `message`, `body`, and `is_plan_gate()` |

In Node.js, a network failure also throws `PxxlAPIError`, with `status` set to `0`.

<Note>
  Response examples show the fields used most often. The API can add fields without breaking existing integrations.
</Note>

title: "Databases API"
description: "Create, inspect, operate, and monitor managed databases."

Database routes need a key scoped to `all` or `database`. Changes need `read_write`. Pass `teamId` to work in a team.

## Create a database

`POST /databases`

<ParamField body="name" type="string" required>
  Database name shown in Pxxl.
</ParamField>

<ParamField body="type" type="string" required>
  `postgres`, `mysql`, `mariadb`, `mongodb`, `redis`, `dragonfly`, `keydb`, or `clickhouse`.
</ParamField>

<ParamField body="description" type="string">
  Short description, up to 500 characters.
</ParamField>

<ParamField body="projectId" type="string">
  Connected project.
</ParamField>

<ParamField body="setDatabaseUrlEnv" type="boolean" default="false">
  Adds the connection URL to the connected project's environment variables.
</ParamField>

<ParamField body="dailyBackupsEnabled" type="boolean" default="false">
  Enables daily backups where supported.
</ParamField>

<ParamField query="teamId" type="string">
  Team that owns the database.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Optional. Stops a retry from creating a second database.
</ParamField>

```bash
curl --request POST \
  "https://server.pxxl.app/api/v3/databases?teamId=team_123" \
  --header "Authorization: Bearer $PXXL_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"name":"app-db","type":"postgres","projectId":"proj_123","dailyBackupsEnabled":true}'
```

```json
{
  "success": true,
  "message": "database created and linked to project",
  "database": {
    "id": "db_123",
    "name": "app-db",
    "type": "postgres",
    "status": "creating",
    "projectId": "proj_123",
    "proxyHost": null,
    "proxyPort": null,
    "dailyBackupsEnabled": true,
    "createdAt": "2026-08-17T08:00:00Z"
  },
  "databaseUrlEnvSet": false,
  "databaseUrlEnvError": ""
}
```

An unsupported `type` returns `400` with an `allowed` list.

## Database endpoints

| Method | Path | Body or parameters | Returns |
| --- | --- | --- | --- |
| `GET` | `/databases` | `teamId?` | `{ success, databases, total }` |
| `POST` | `/databases` | Creation body above | `{ success, message, database }` |
| `GET` | `/databases/{databaseId}` | `teamId?` | `{ success, database }` |
| `PATCH` | `/databases/{databaseId}` | `name?`, `description?`, `dailyBackupsEnabled?` | `{ success, database }` |
| `DELETE` | `/databases/{databaseId}` | `teamId?` | `{ success, message }` |
| `POST` | `/databases/{databaseId}/start` | `teamId?` | `{ success, message, infra, database }` |
| `POST` | `/databases/{databaseId}/stop` | `teamId?` | `{ success, message, infra, database }` |
| `POST` | `/databases/{databaseId}/restart` | `teamId?` | `{ success, message, infra, database }` |
| `GET` | `/databases/{databaseId}/stats` | `teamId?` | `{ success, stats }` |
| `GET` | `/databases/{databaseId}/metrics` | `teamId?` | `{ success, metrics, timeline, runtime }` |
| `GET` | `/databases/{databaseId}/usage` | `teamId?` | `{ success, usage }` |
| `GET` | `/databases/{databaseId}/tables` | `teamId?` | `{ success, tables }` |
| `GET` | `/databases/{databaseId}/settings` | `teamId?` | `{ success, settings }` |
| `PATCH` | `/databases/{databaseId}/scaling` | `memory?`, `cpu?` | `{ success, message, settings }` |
| `PATCH` | `/databases/{databaseId}/ssl` | `enabled` | `{ success, message, settings }` |

## Runtime actions

```bash
curl --request POST \
  https://server.pxxl.app/api/v3/databases/db_123/restart \
  --header "Authorization: Bearer $PXXL_API_KEY"
```

```json
{
  "success": true,
  "message": "database restarted",
  "database": { "id": "db_123", "status": "running" }
}
```

## Usage

`GET /databases/{databaseId}/usage` returns storage, connection, and transfer totals.

```json
{
  "success": true,
  "usage": {
    "storageBytes": 104857600,
    "storageLimitBytes": 10737418240,
    "activeConnections": 3,
    "connectionCount": 1204,
    "bytesIn": 52428800,
    "bytesOut": 157286400,
    "transferBytes": 209715200,
    "backups": []
  }
}
```

## Credentials

Connection passwords are not returned to API keys. `GET /databases/{databaseId}/credentials/{field}` accepts only a recent signed-in dashboard session and returns `403` for API keys. Copy credentials from the dashboard, or set `setDatabaseUrlEnv` when you create the database so your project gets the URL directly.

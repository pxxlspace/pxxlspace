---
title: "MCP API"
description: "Call Pxxl tools and resources through JSON-RPC over HTTP."
---

MCP uses a separate endpoint:

```text
https://mcp.pxxl.app/mcp
```

It takes an MCP key, not a regular API key. Create one by adding an MCP connection in the dashboard (see [MCP](/ai/mcp)). The connection decides which projects and tools the key can reach. MCP needs a Plus, Pro, or Enterprise plan.

## Headers

<ParamField header="Authorization" type="string" required>
  `Bearer` followed by your MCP key. You can send the key in `X-Pxxl-MCP-Key` instead.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Must be `application/json`. Anything else returns `415`.
</ParamField>

<ParamField header="MCP-Protocol-Version" type="string" default="2025-11-25">
  Protocol version used by the client. `2025-03-26`, `2025-06-18`, and `2025-11-25` are supported.
</ParamField>

## JSON-RPC request

<ParamField body="jsonrpc" type="string" required>
  Must be `2.0`.
</ParamField>

<ParamField body="id" type="string | number">
  Client-generated request ID. Leave it out for notifications, which return `202` with no body.
</ParamField>

<ParamField body="method" type="string" required>
  MCP method such as `tools/list`.
</ParamField>

<ParamField body="params" type="object">
  Method parameters.
</ParamField>

## MCP methods

| Method | Parameters | Returns |
| --- | --- | --- |
| `initialize` | `protocolVersion`, capabilities, client info | Protocol version, capabilities, server info, instructions |
| `ping` | None | Empty result |
| `tools/list` | None | Tools allowed for this connection, with schemas |
| `tools/call` | `name`, `arguments` | Tool output as JSON text in `content` |
| `resources/list` | None | Resource definitions |
| `resources/templates/list` | None | Resource templates |
| `resources/read` | `uri` | Resource contents |
| `resources/subscribe`, `resources/unsubscribe` | `uri` | Subscription result |
| `prompts/list`, `prompts/get` | `name` for `get` | Prompts |
| `completion/complete` | Completion reference and argument | Suggestions |
| `tasks/get`, `tasks/list`, `tasks/result`, `tasks/cancel` | Task ID | Long-running tool calls |

A `GET` to the endpoint with `Accept: text/event-stream` opens a stream of server events. Without that header it returns `204`.

## List tools

```bash
curl https://mcp.pxxl.app/mcp \
  --header "Authorization: Bearer $PXXL_MCP_API_KEY" \
  --header "Content-Type: application/json" \
  --header "MCP-Protocol-Version: 2025-11-25" \
  --data '{"jsonrpc":"2.0","id":"1","method":"tools/list","params":{}}'
```

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "result": {
    "tools": [
      {
        "name": "projects_list",
        "description": "List only the projects explicitly selected for this MCP connection.",
        "inputSchema": { "type": "object", "properties": {} }
      }
    ]
  }
}
```

## Call a tool

```bash
curl https://mcp.pxxl.app/mcp \
  --header "Authorization: Bearer $PXXL_MCP_API_KEY" \
  --header "Content-Type: application/json" \
  --header "MCP-Protocol-Version: 2025-11-25" \
  --data '{"jsonrpc":"2.0","id":"2","method":"tools/call","params":{"name":"projects_list","arguments":{}}}'
```

```json
{
  "jsonrpc": "2.0",
  "id": "2",
  "result": {
    "content": [
      { "type": "text", "text": "{\"projects\":[],\"total\":0}" }
    ],
    "isError": false
  }
}
```

Tools that change or delete data need `"confirm": true` in `arguments`. Pass `idempotency_key` when you may retry a write.

## Error responses

JSON-RPC errors use the top-level `error` field.

```json
{
  "jsonrpc": "2.0",
  "id": "2",
  "error": {
    "code": -32602,
    "message": "tool arguments must be an object"
  }
}
```

| Code | HTTP status | Meaning |
| --- | --- | --- |
| `-32001` | `401` | MCP key missing or invalid |
| `-32003` | `403` or `402` | Connection disabled, owner blocked, origin not allowed, or plan too low |
| `-32600` | `400` | Invalid JSON-RPC request |
| `-32601` | `200` | Method not found |
| `-32602` | `200` | Invalid tool name or arguments |

A tool can also return `isError: true` inside `result`. Check both forms.

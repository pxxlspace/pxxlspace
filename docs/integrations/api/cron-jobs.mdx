title: "Cron jobs API"
description: "Schedule HTTP requests, control jobs, trigger runs, and inspect history."
---

Cron routes need a key scoped to `all`, `cron`, or `cronjobs`. Changes need `read_write`.

## Create a cron job

`POST /cli/cronjobs`

<ParamField body="name" type="string" required>
  Job name shown in Pxxl.
</ParamField>

<ParamField body="schedule" type="string" required>
  Five-field cron expression.
</ParamField>

<ParamField body="url" type="string" required>
  Endpoint called by the job.
</ParamField>

<ParamField body="method" type="GET | POST | PUT | PATCH | DELETE" default="GET">
  HTTP method sent to the endpoint.
</ParamField>

<ParamField body="headers" type="object">
  Request headers sent by Pxxl.
</ParamField>

<ParamField body="timeoutSeconds" type="number" default="30">
  Maximum execution time, from 1 to 30 seconds.
</ParamField>

<ParamField body="projectId" type="string">
  Associated project.
</ParamField>

<ParamField body="teamId" type="string">
  Owning team.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
  Optional. A retry with the same key returns the first job instead of creating another.
</ParamField>

```bash
curl --request POST \
  https://server.pxxl.app/api/v3/cli/cronjobs \
  --header "Authorization: Bearer $PXXL_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"name":"nightly cleanup","schedule":"0 2 * * *","url":"https://api.example.com/jobs/cleanup","method":"POST","timeoutSeconds":30}'
```

**Response** `201`

```json
{
  "id": "cron_123",
  "projectId": null,
  "teamId": null,
  "name": "nightly cleanup",
  "schedule": "0 2 * * *",
  "url": "https://api.example.com/jobs/cleanup",
  "method": "POST",
  "headers": {},
  "timeoutSeconds": 30,
  "status": "active",
  "consecutiveFailures": 0,
  "disabledReason": null,
  "lastRunAt": null,
  "nextRunAt": "2026-08-18T02:00:00Z"
}
```

Missing fields return `400`. A bad method or URL returns `422`.

## Cron endpoints

| Method | Path | Body or parameters | Returns |
| --- | --- | --- | --- |
| `GET` | `/cli/cronjobs` | `teamId?` | `{ cronJobs }` |
| `POST` | `/cli/cronjobs` | Creation body above | `201` with the cron job |
| `GET` | `/cli/cronjobs/{cronJobId}` | None | Cron job |
| `PUT` | `/cli/cronjobs/{cronJobId}` | `name?`, `schedule?`, `url?`, `method?`, `headers?`, `timeoutSeconds?`, `status?`, `projectId?` | Updated cron job |
| `DELETE` | `/cli/cronjobs/{cronJobId}` | None | `{ message }` |
| `POST` | `/cli/cronjobs/{cronJobId}/start` | None | `{ message, cronJob }` |
| `POST` | `/cli/cronjobs/{cronJobId}/stop` | None | `{ message, cronJob }` |
| `POST` | `/cli/cronjobs/{cronJobId}/trigger` | None | `202` with `{ message, runId }` |
| `GET` | `/cli/cronjobs/{cronJobId}/runs` | `page?`, `limit?` (default 20) | Paginated runs |
| `POST` | `/cli/cronjobs/validate-schedule` | `{ schedule }` | `{ valid, nextRun }` |
| `POST` | `/cli/cronjobs/validate-url` | `{ url }` | `{ reachable, statusCode, error? }` |

## Trigger a run

```bash
curl --request POST \
  https://server.pxxl.app/api/v3/cli/cronjobs/cron_123/trigger \
  --header "Authorization: Bearer $PXXL_API_KEY"
```

**Response** `202`

```json
{
  "message": "Cron job queued for execution",
  "runId": "run_123"
}
```

## Run history

```json
{
  "runs": [
    {
      "id": "run_123",
      "cronJobId": "cron_123",
      "status": "success",
      "statusCode": 200,
      "output": "ok",
      "error": null,
      "timedOut": false,
      "startedAt": "2026-08-17T08:05:00Z",
      "finishedAt": "2026-08-17T08:05:01Z"
    }
  ],
  "total": 1,
  "page": 1,
  "limit": 20,
  "totalPages": 1
}
```

`status` is `running`, `success`, or `failed`. `output` holds up to 10 KB of the response body.

<Note>
  Job headers can contain secrets. Keep cron management in trusted server code.
</Note>

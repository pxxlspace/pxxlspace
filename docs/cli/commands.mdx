Run `pxxl help <area>` for the same information in your terminal. Arguments in `[brackets]` are optional. When a project or resource id is optional and you're in a terminal, the CLI shows a picker.

## Account

| Command | What it does |
| --- | --- |
| `pxxl login --api-key <key>` | Check and save an API key. `-k` works too. |
| `pxxl logout` | Delete the saved key and team. |
| `pxxl whoami` | Show the signed-in account. Alias: `pxxl status`. |
| `pxxl stats` | Platform stats for your account or `--team`. |
| `pxxl usage` | Usage for your account or `--team`. |
| `pxxl version` | Print the CLI version. Also `--version`, `-v`. |

## Set up a project

| Command | What it does |
| --- | --- |
| `pxxl init` | Write `pxxl.toml` and `.pxxlignore` in the current folder. |
| `pxxl init --new [template]` | Copy a starter template. No template name opens a picker. |
| `pxxl link [project-id]` | Link this folder to an existing project. Saved in `pxxl.toml`. |
| `pxxl unlink` | Remove the link from `pxxl.toml`. |
| `pxxl doctor` | Check auth, internet, git, config files, package manager, build and start commands, env files, and upload size. |
| `pxxl inspect` | Show the detected framework, package manager, runtime, commands, env files, and upload size. |

`pxxl init` flags: `--new [template]`, `--name <name>`, `--dir <path>`, `--domain <suffix>`, `--port <n>`, `--deploy`, `--no-deploy`.

Templates: `astro-npm`, `dockerfile-node`, `express-bun`, `express-npm`, `express-pnpm`, `express-yarn`, `fastify-pnpm`, `go-http`, `hono-bun`, `microservices-node`, `nextjs-pnpm`, `node-typescript-npm`, `php-basic`, `python-django`, `python-fastapi`, `python-flask`, `rust-axum`, `static-cdn-gallery`, `sveltekit-pnpm`, `turbo-monorepo`, `vite-react-bun`, `vite-react-npm`, `vite-react-pnpm`, `vite-react-yarn`, `vue-vite-pnpm`.

Project names are 3 to 63 characters: lowercase letters, numbers, and hyphens.

## Deploy

| Command | What it does |
| --- | --- |
| `pxxl deploy` | Zip this folder, upload it, follow the build, and print the live URL. |
| `pxxl redeploy <project-id>` | Queue a new build of the project's source. Doesn't follow it. |
| `pxxl watch` | Follow the current build, or wait for the next one (a git push, dashboard deploy, or redeploy). |
| `pxxl ls` | This project's deployments. `--limit <n>` (default 20). |
| `pxxl rollback [deployment-id]` | Make an earlier deployment live again. Alias: `promote`. |
| `pxxl rebuild [deployment-id]` | Rebuild a deployment. Defaults to the latest. |
| `pxxl cancel [deployment-id]` | Stop a running build. Defaults to the one in progress. |
| `pxxl errors [deployment-id]` | Show what failed in a build, grouped, with hints. Defaults to the latest failure. |

`pxxl deploy` flags:

| Flag | Meaning |
| --- | --- |
| `--name <name>` | Project name (first deploy). |
| `--domain <suffix>` | Pxxl domain suffix, such as `pxxl.pro`. |
| `--port <n>` | Port your app listens on. |
| `-m, --message <text>` | Deploy message. |
| `--dir <path>` | Folder to deploy. |
| `--yes` | Don't ask questions. |
| `--no-wait` | Upload and exit without following the build. |
| `--quiet` | Follow the build but hide log lines. |

`pxxl redeploy` flags: `--commit <sha>` (or `--sha`), `-m, --message <text>`.

`pxxl watch` flags: `--project <id>`, `--once` (stop after one build), `--quiet`.

Uploads skip files in [`.pxxlignore`](/reference/pxxl-toml#pxxlignore), symlinks, and files that look like private keys (`*.pem`, `*.key`, `id_rsa`, `credentials.json`). The limit is 12,000 files and 220 MiB.

## Projects

| Command | What it does |
| --- | --- |
| `pxxl projects list` | List projects. `--page`, `--limit` (default 10). |
| `pxxl projects get [id]` | Show one project. |
| `pxxl projects update` | Change build settings (applied on the next deploy). |
| `pxxl projects auto-deploy on\|off` | Turn deploy-on-push on or off. |
| `pxxl projects history` | Rollback history. |
| `pxxl projects usage` | Compute usage. |
| `pxxl rm --project <id>` | Delete a project. Asks you to type the name unless `--yes`. |

`pxxl projects update` flags: `--build-command`, `--start-command`, `--install-command`, `--root` (base directory), `--branch`, `--framework`, `--node-version`, `--health-path`, `--name`, `--port`.

```bash
pxxl projects update --start-command "node dist/server.js" --port 8080
```

## Run and test

| Command | What it does |
| --- | --- |
| `pxxl dev` | Run your dev server locally with the project's env vars. |
| `pxxl dev --tunnel` | Same, and share it on a public URL. |
| `pxxl curl [path]` | Send a request to your live app. |
| `pxxl restart` | Restart the running app. |
| `pxxl pause` / `pxxl resume` | Pause or resume the app. |
| `pxxl cache purge` | Clear the CDN cache. `--wait` waits until done. |
| `pxxl open` | Open the project in the dashboard. `--live` opens the site. |
| `pxxl pull <project-id> [folder]` | Clone or update the project's Git repository. |

`pxxl dev` picks `npm run dev` (or your package manager), `python manage.py runserver`, or `go run .`. Override with `pxxl dev -- <command>`. Flags: `--port <n>` (default 3000), `--no-env`, `--tunnel`. Your shell's variables win over Pxxl's. The process also gets `PXXL_DEV=1`.

```bash
pxxl dev -- bun run dev
pxxl curl /api/health -i
pxxl curl /api/users -X POST -d '{"name":"Ada"}'
```

`pxxl curl` flags: `-X, --method`, `-H, --header "Name: value"`, `-d, --data`, `-i, --include`, `--full`, `--url`.

## Environment variables

| Command | What it does |
| --- | --- |
| `pxxl env list [project-id]` | List variable names. |
| `pxxl env add KEY [value]` | Add or update a variable. Reads the value from stdin or a prompt if you leave it out. `--plain` stores it as non-secret. |
| `pxxl env get KEY` | Print one value. |
| `pxxl env rm KEY` | Delete a variable. |
| `pxxl env diff [project-id]` | Compare a local file with Pxxl. `--file` (default `.env`). |
| `pxxl env push [project-id]` | Upload a local file. `--file` (default `.env`), `--replace` to replace all remote values. |
| `pxxl env pull [file]` | Write all variables to a file (default `.env.local`) with mode 600. |

Add `--global` to `list`, `diff`, or `push` for workspace-wide variables. Redeploy after changes.

```bash
echo "sk_live_123" | pxxl env add STRIPE_KEY
pxxl env push --file .env.production
```

## Domains

| Command | What it does |
| --- | --- |
| `pxxl domains list` | Your domains. |
| `pxxl domains search <name>` | Check if a domain is available. |
| `pxxl domains tlds` | Domain prices. |
| `pxxl domains connect <domain...>` | Add domains to the linked project. |
| `pxxl domains disconnect [domain]` | Remove a domain from the project. |
| `pxxl domains check <domain>` | Check DNS and HTTPS from your machine and from Pxxl. |
| `pxxl domains verify [domain]` | Check the project's DNS records. |
| `pxxl domains status [id]` | DNS, SSL, and zone readiness. |
| `pxxl domains resync [domain]` | Republish the proxy route and SSL. |
| `pxxl domains stats [domain]` | Proxy traffic. `--timeframe 24h\|48h\|72h\|7d\|30d`. |
| `pxxl domains cert [id]` | Download the public certificate. `--out <file>`. |
| `pxxl domains switch-to-pxxl-dns [id]` | Move DNS to Pxxl. |
| `pxxl domains nameservers verify\|set\|reset [id]` | Manage nameservers. `set --values ns1,ns2`. |
| `pxxl domains records [list\|add\|update\|delete] [id]` | Manage DNS records. |
| `pxxl domains purchase --data '<json>'` | Create a domain invoice. |
| `pxxl domains orders` | Domain orders. |

`domains connect` flags: `--project <id>`, `--service <id>` and `--port <n>` to route to one service in a monorepo.

`domains records` flags: `--type` (default `A`), `--name` (default `@`), `--value`, `--ttl` (default 60), `--priority`, `--record-id`.

```bash
pxxl domains connect example.com www.example.com
pxxl domains records add <domain-id> --type CNAME --name blog --value my-blog.pxxl.pro
```

### Reselling

```bash
pxxl domains reseller login pxxl_rsl_...
pxxl domains reseller quote example.cv
pxxl domains reseller buy example.cv --customer-ref cust_42
pxxl domains reseller dns set example.cv --type A --name @ --value 203.0.113.10
pxxl domains reseller nameservers set example.cv ns1.example.net ns2.example.net
pxxl domains reseller --help
```

Pro and up. Charged to your wallet. See [Domain reseller](/tools/domain-reseller).

## Cron jobs

| Command | What it does |
| --- | --- |
| `pxxl cron list` | Your jobs. |
| `pxxl cron create` | Create a job. |
| `pxxl cron get\|update\|delete [id]` | Show, change, or delete a job. |

```bash
  --url https://api.example.com/jobs/report --method POST \
  --headers '{"Authorization":"Bearer token"}'
```

## Tunnels

| Command | What it does |
| --- | --- |
| `pxxl tunnel <port\|url>` | Share a local port on a public URL. |
| `pxxl tunnel list` | Your tunnels. |
| `pxxl tunnel create <name>` | Create a named tunnel and get a token for the standalone binary. |
| `pxxl tunnel connect <name>` | Connect a named tunnel. `--to <port>`. |
| `pxxl tunnel rotate <name>` | New token for the standalone binary. |
| `pxxl tunnel delete <name>` | Delete a tunnel. |

Flags: `--name`, `--auth user:password`, `--header "N: v"`, `--response-header "N: v"`, `--host-header rewrite|preserve|<host>`, `--strict-tls`, `--quiet`. See [Tunnels](/tools/tunnels).

## Servers

| Command | What it does |
| --- | --- |
| `pxxl servers list` | Your linked servers. |
| `pxxl servers add <name>` | Create a server and print its one-time install command. |
| `pxxl servers show [server]` | Server details. |
| `pxxl servers health [server]` | Health and agent status. |
| `pxxl servers metrics [server]` | CPU, memory, disk. |
| `pxxl servers apps [server]` | Apps running on the server. |
| `pxxl servers events [server]` | Recent events. `--limit`. |
| `pxxl servers alerts [server]` | Open and resolved alerts. |
| `pxxl servers ops` | List the [safe operations](/servers/operations). |
| `pxxl servers run [server] <op>` | Run an operation. `--app`, `-n, --lines`, `--change` (needed for change ops), `--yes`. |
| `pxxl servers restart\|start\|stop\|logs [server] --app <name>` | Control one app, or read its last 500 log lines. |
| `pxxl servers update [server]` | Update the agent now. Asks first. |
| `pxxl servers prune [server]` | Remove unused container images. Asks first. |
| `pxxl servers settings [server] --set key=value` | Show or change `alertOffline`, `alertCrashes`, `alertResources`, `alertEmail`, `autoUpdate`. |
| `pxxl servers rename [server] <name>` | Rename. |
| `pxxl servers link [server]` | New install command (to reinstall the agent). |
| `pxxl servers rm [server] --yes` | Remove the server from Pxxl. |

`[server]` is an id, name, or hostname. Leave it out if you have one server. See [Servers](/servers/overview).

## MCP

Talk to the [Pxxl MCP server](/ai/mcp) from the terminal. Output is JSON.

```bash
pxxl mcp tools
pxxl mcp call <tool> --data '{"projectId":"..."}'
pxxl mcp resources
pxxl mcp read <uri>
pxxl mcp ping
```

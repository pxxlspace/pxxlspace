Pxxl MCP lets an AI client work with approved projects, deployments, domains, databases, storage, cron jobs, and other resources. The connection uses HTTP. A JavaScript SDK is optional, not required.

MCP connections are available on Plus, Pro, and Enterprise plans.

## What MCP can do

An approved connection can inspect or update the resources covered by its scopes. Resource-specific allowlists let you select only the projects, domains, databases, buckets, teams, or environments the client should see.

Secrets, environment values, API keys, payment details, passwords, and authentication administration are not returned through MCP.

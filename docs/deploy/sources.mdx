| Source | Use it when |
| --- | --- |
| **GitHub** | Your code is on GitHub. Pushes deploy automatically. |
| **GitLab** | Your code is on GitLab. |
| **Pxxl Drop** | You want to upload a zip or a built folder once. |
| **Docker image** | You already have an image on Docker Hub or another registry. |
| **Dockerfile** | You want Pxxl to build your Dockerfile. |
| **WordPress** | You want a managed WordPress site. |
| **Templates** | You want to start from a ready-made app. |
| **Import projects** | You're moving a project from another host. |
| **CLI** | You want to deploy a local folder with `pxxl deploy`. See [Deploy with the CLI](/get-started/cli). |

Some sources need a paid plan.

## GitHub

<Steps>
  <Step title="Install the GitHub App">
    In **Deploy**, choose **GitHub** and install the Pxxl GitHub App. Give it access to the repositories you want.
  </Step>
  <Step title="Pick the repository and branch">
    Pxxl scans the repo and fills in the build settings.
  </Step>
  <Step title="Deploy">
    Check the settings and choose **Deploy Project**.
  </Step>
</Steps>

After that:

- **Every push** to the deploy branch starts a new deployment.
- **Pull requests** can get their own preview deployment with its own URL. Turn on preview environments in the project's build settings.
- Commits to other branches don't touch production.

## Docker

**Docker image**: enter the image name, such as `ghcr.io/acme/api:1.4.0`. Pxxl pulls and runs it as a web service. Set the port your container listens on.

**Dockerfile**: Pxxl builds the image from the `Dockerfile` in your base directory. Your app should still listen on `$PORT`:

```dockerfile
FROM node:22-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --omit=dev
COPY . .
ENV PORT=3000
EXPOSE 3000
CMD ["node", "server.js"]
```

## Pxxl Drop

Drag a zip or a built folder (for example `dist`) into **Pxxl Drop**. Good for one-off static sites and demos. There's no Git history, so redeploys need a new upload.

## Monorepos

Set **Base directory** to the folder of the app you want, such as `apps/web`. For several apps in one repo, see [Monorepos and multiple services](/deploy/monorepos).

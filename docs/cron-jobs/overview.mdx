Pxxl Cron Jobs send an HTTP request to your application on a schedule. They are useful for cleanup, cache refreshes, report generation, webhook delivery, health checks, and other work that should happen without a visitor opening the application.

Cron Jobs are available on Plus, Pro, and Enterprise plans.

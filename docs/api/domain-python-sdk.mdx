Use the Python SDK from backend jobs, admin tools, automation scripts, or CI tasks that need to manage domains on Pxxl.

Use an API key with `scope=domain`, `scope=domains`, or `scope=all`. Read-only keys can list and check domains. Write keys can connect domains, resync proxy routes, disconnect domains, and modify DNS records.

## Install

```bash
pip install pxxl
```

```python
from pxxl import PxxlClient

pxxl = PxxlClient(api_key="pxxl_...")
```

## Connect a domain

Attach a hostname to a project. If the project already has an active deployment, Pxxl registers the proxy route immediately.

<ParamField body="domain" type="string" required>
  Hostname to connect, such as `example.com` or `api.example.com`.
</ParamField>

<ParamField body="project_id" type="string" required>
  Project that should receive traffic for the domain.
</ParamField>

<ParamField body="microservice_id" type="string">
  Optional microservice target for monorepos and multi-service projects.
</ParamField>

<ParamField body="service_id" type="string">
  Alias for `microservice_id`.
</ParamField>

<ParamField body="service_alias" type="string">
  Alias for `microservice_id`.
</ParamField>

<ParamField body="team_id" type="string">
  Spaceship context for team-owned projects and domains.
</ParamField>

```python
connected = pxxl.connect_domain(
    "example.com",
    project_id="proj_123",
)

print(connected["domainId"])
print(connected["expectedRecords"])
```

For a microservice route:

```python
connected = pxxl.connect_domain(
    "api.example.com",
    project_id="proj_123",
    service_alias="api",
)

print(connected["serviceAlias"])
```

<Tip>
  Adding a domain does not require a redeploy when the project already has a healthy active deployment. Verify DNS after updating records, then resync if proxy or SSL settings changed.
</Tip>

## Check and verify

Use these methods to check availability, verify DNS, and inspect activation status.

<ParamField body="domain" type="string" required>
  Hostname to check or verify.
</ParamField>

<ParamField body="project_id" type="string" required>
  Project that owns the domain binding.
</ParamField>

<ParamField body="domain_id" type="string" required>
  Pxxl domain ID returned by connect, list, or dashboard domain pages.
</ParamField>

<ParamField body="team_id" type="string">
  Spaceship context for team-owned domains.
</ParamField>

```python
check = pxxl.check_domain("example.com")

verify = pxxl.verify_domain_record(
    "example.com",
    project_id="proj_123",
)

activation = pxxl.activate_domain("dom_123")

status = pxxl.get_domain_connection_status("dom_123")
print(status["ssl"])
print(status["proxy"])
```

`verify_domain_record` performs an immediate expected-record check for the project domain. Pxxl also auto-detects pending external domains for up to 24 hours after connection, checking every 5 minutes until the expected DNS record resolves.

`get_domain_connection_status` uses `.cv` managed zone status for `.cv` domains and the generic activation check for other TLDs. `get_domain_zone_status` remains available for older code and now follows the same dynamic behavior.

## Resync the proxy route

Use `resync_domain_proxy` after changing DNS, SSL settings, force HTTPS, force www, the connected project, or the microservice target. It refreshes the active proxy route and certificate state without rebuilding the project.

<ParamField body="domain" type="string" required>
  Hostname whose proxy route should be refreshed.
</ParamField>

<ParamField body="team_id" type="string">
  Spaceship context for team-owned domains.
</ParamField>

```python
resync = pxxl.resync_domain_proxy("example.com")

print(resync["status"])
print(resync["message"])
```

For a team-owned domain:

```python
resync = pxxl.resync_domain_proxy(
    "example.com",
    team_id="team_123",
)
```

This method calls `POST /api/v3/cli/domains/:domain/resync`. It requires `read_write` permission.

## Disconnect a domain

Use `disconnect_domain` when a custom domain should stop routing to a project. It removes the project binding and proxy route. It does not delete the domain from your registrar.

<ParamField body="domain" type="string" required>
  Hostname to disconnect.
</ParamField>

<ParamField body="project_id" type="string">
  Project currently connected to the domain. Include it when possible to avoid removing the wrong binding.
</ParamField>

<ParamField body="team_id" type="string">
  Spaceship context for team-owned domains.
</ParamField>

```python
deleted = pxxl.disconnect_domain(
    "example.com",
    project_id="proj_123",
)

print(deleted)
```

For a team-owned domain:

```python
deleted = pxxl.disconnect_domain(
    "example.com",
    project_id="proj_123",
    team_id="team_123",
)
```

## DNS records

Pxxl-managed domains can be edited through the SDK. Pxxl validates record conflicts before saving, including invalid `CNAME` and `A` combinations for the same hostname.

<ParamField body="domain_id" type="string" required>
  Pxxl domain ID for the managed zone.
</ParamField>

<ParamField body="type" type="string" required>
  DNS record type, such as `A`, `AAAA`, `CNAME`, `TXT`, or `MX`.
</ParamField>

<ParamField body="name" type="string" required>
  Record name. Use `@` for the apex/root.
</ParamField>

<ParamField body="value" type="string" required>
  DNS record value.
</ParamField>

<ParamField body="ttl" type="number">
  Time to live in seconds.
</ParamField>

<ParamField body="priority" type="number">
  Required for `MX` records. Lower values are preferred first by mail senders.
</ParamField>

```python
records = pxxl.list_domain_dns_records("dom_123")

created = pxxl.create_domain_dns_record("dom_123", {
    "type": "A",
    "name": "@",
    "value": "193.181.212.65",
    "ttl": 60,
})

mx_record = pxxl.create_domain_dns_record("dom_123", {
    "type": "MX",
    "name": "@",
    "value": "mail.example.com",
    "priority": 10,
    "ttl": 60,
})

updated = pxxl.update_domain_dns_records("dom_123", {
    "recordId": "rec_123",
    "type": "A",
    "name": "@",
    "value": "193.181.212.66",
})

pxxl.delete_domain_dns_record("dom_123", {
    "recordId": "rec_123",
})
```

`CNAME`, `MX`, and `NS` values must be hostnames such as `app.example.com`, `mail.example.com`, or `ns1.example.com`. Pxxl rejects URLs, IP addresses, spaces, `@`, and single-label values such as `mail`.

## Certificates

```python
pem = pxxl.download_domain_certificate("dom_123")

with open("example.com.pem", "wb") as file:
    file.write(pem)
```

## Team context

```python
team_pxxl = PxxlClient(api_key="pxxl_...", team_id="team_123")
domains = team_pxxl.list_domains()
```

Usage limits are still enforced against the owning user account, even when a team context is selected.

## Error handling

When a plan limit is reached, the SDK raises `PxxlAPIError`. Use the status code and body to show the exact limit reason.

```python
from pxxl import PxxlAPIError

try:
    pxxl.connect_domain("example.com", project_id="proj_123")
except PxxlAPIError as error:
    print(error.status_code)
    print(error.message)
    print(error.body.decode())
```

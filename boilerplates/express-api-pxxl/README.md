# Express API Pxxl Boilerplate

Deploy a production-ready Node API starter on Pxxl with custom domains, SSL, global routing, logs, and simple GitHub deploys.

## Local

```bash
npm install
npm run dev
```

## Deploy on Pxxl

Import the repo at [pxxl.app](https://pxxl.app). Pxxl detects Node and runs `npm run start` on the assigned `PORT`.
